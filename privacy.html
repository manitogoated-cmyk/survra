Privacy Policy

Last updated: November 11, 2026

This policy covers Survra Studio, the internal tool used to publish videos to the Survra YouTube channel.

What we access

With the channel owner's permission, granted through Google's OAuth consent screen, Survra Studio accesses the owner's own YouTube channel to upload videos, set video details and schedules, and read the channel's own analytics reports.

What we do not do

We do not access other users' accounts, collect personal information from viewers, sell or share any data, or use Google user data for advertising.

Storage and security

Authorization tokens are kept only in encrypted secret storage and are never published. Analytics figures are used only to plan and improve the channel's own videos.

Google API Services

Survra Studio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

The owner can revoke access at any time at myaccount.google.com/permissions.
